Class Descriptions:
Williams Domain

Stable and regular domain pattern with clear, well-defined crystal structure. Characterized by consistent and repetitive domain formation.

Fluctuating Williams Domain

Domain pattern with dynamic fluctuations, showing structural changes or instability in the pattern. Displays variations in domain shape and size.

Grid Pattern

Grid or lattice pattern with regular periodic structure forming box-like patterns. Has high symmetry and consistent repeating patterns.
